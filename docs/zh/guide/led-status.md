# LED 状态参考

板载 WS2812 RGB LED 通过颜色和闪烁指示设备工作状态。

## LED 状态表

| 状态 | 颜色 | 说明 |
|------|------|------|
| USB 未连接 | **红色常亮** | USB 设备未插入或未就绪 |
| BLE 广播中 | **紫色闪烁** | USB 已就绪，等待主机连接 |
| 已连接 | **绿色常亮** | USB + 至少 1 台 BLE 主机已连接，正常工作中 |
| 配对码输入中 | **紫色常亮** | 等待用户在键盘上输入配对码 |
| 错误 | **红色常亮** | USB 通信异常 |

## 快速参考

| 颜色 | 含义 |
|------|------|
| 🔴 红色 | USB 问题（未连接或错误） |
| 🟣 紫色 | 蓝牙活动（闪烁 = 广播等待连接，常亮 = 配对中） |
| 🟢 绿色 | 正常工作（USB + BLE 已连接） |

> **注意**：红色常亮可能表示"USB 未连接"或"错误" — 请检查 USB 设备是否正确连接。
