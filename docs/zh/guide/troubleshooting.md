# 常见问题

常见问题及解决方法。

## 设备无法进入正常模式（卡在配网状态）

**可能的原因：**
- 设备未激活（没有有效的激活码）
- WiFi 凭据未配置
- 配网过程中断或失败

**尝试：**
1. 打开桌面客户端 — 它会自动检测设备并引导你完成配网
2. 如果激活失败，确认激活码与设备匹配
3. 如果 WiFi 连接失败，检查网络是否为 2.4GHz（ESP32-S3 不支持 5GHz）
4. 设备会一直在配网模式下等待 — 没有超时限制

## LED 显示红色常亮

**可能的原因：**
- 未连接 USB 设备
- USB 设备不兼容
- USB 通信错误

**尝试：**
1. 检查键盘/鼠标是否已牢固连接
2. 换一个 USB 设备试试
3. 重新上电（断开后重新连接电源）

## 蓝牙中搜索不到 "Loommii-HID"

**可能的原因：**
- 设备仍处于配网模式（紫色闪烁）— 需要先通过桌面客户端完成配网
- 已达到最大连接数（3 台）
- 蓝牙信号干扰

**尝试：**
1. 检查 LED 状态 — 如果紫色闪烁，说明设备需要配网，打开桌面客户端完成设置
2. 如果 LED 已是绿色常亮，说明已有主机连接 — 可以直接连接新主机（最多 3 台）
3. 重新上电
4. 靠近开发板

## 桌面客户端无法发现设备

**可能的原因：**
- 设备不在配网模式（未广播配网服务）
- 电脑蓝牙未开启
- BLE 信号距离问题

**尝试：**
1. 确认 LED 为紫色闪烁（配网模式）
2. 开启电脑蓝牙
3. 将开发板靠近电脑
4. 如果 LED 为绿色常亮，说明设备已完成配网 — 可以通过 WiFi 局域网连接

## 配对码不显示

部分主机可能需要几秒钟才能生成配对码。如果一直没有显示：

1. 确认选择了正确的设备名称
2. 取消配对后重试
3. 换一台主机（如手机）试试，以排除问题

## 配对后键盘输入无反应

**尝试：**
1. 取消配对后重新配对
2. 检查 LED 状态 — 是否显示已连接状态？
3. 使用 `Scroll Lock + 1` / `2` / `3` 切换到其他已连接主机再切回来

## 鼠标移动卡顿或延迟

- 确保开发板和主机之间没有遮挡
- 缩短开发板与主机之间的距离
- 检查是否有其他蓝牙设备干扰

## 连接频繁断开

- 尝试将开发板靠近主机
- 检查 USB 供电是否稳定 — 供电不足会导致间歇性故障
- 尝试切换到其他已连接主机再切回来

## 配网后 WiFi 无法连接

**可能的原因：**
- 配网时输入了错误的 WiFi 密码
- 连接的是 5GHz 网络（ESP32-S3 仅支持 2.4GHz）
- 路由器距离开发板太远

**尝试：**
1. 恢复出厂设置后重新配网，输入正确的 WiFi 凭据
2. 确认连接的是 2.4GHz 网络
3. 将开发板靠近路由器

## Web 烧录提示 "获取清单失败"

- 请使用 **Chrome 或 Edge** 浏览器（Firefox 和 Safari 不支持 Web Serial）
- 确保通过 **HTTPS**（或 localhost）访问页面
- 换一根 USB 数据线 — 有些线只支持充电，不能传输数据

## 仍有问题？

如果以上步骤无法解决，请在 GitHub 上[提交 Issue](https://github.com/loommii/ESP32S3-USB-HID-To-BLE-Releases/issues)。
