# 首次使用

请按照以下步骤首次设置您的 USB HID 转 BLE 桥接器。

## 准备工作

- 已烧录固件的 ESP32-S3 开发板
- USB 键盘和/或鼠标
- 支持蓝牙的电脑、手机或平板（用于 BLE HID 连接）
- [桌面客户端](https://github.com/loommii/ESP32S3-USB-HID-To-BLE-Releases/releases)（首次设置需要，支持 macOS / Windows）

## 首次设置（配网流程）

首次启动（或恢复出厂设置后），设备会自动进入**配网模式**。需要使用桌面客户端完成激活和 WiFi 配置。

### 1. 上电

将 USB 键盘和/或鼠标插入 ESP32-S3 开发板，然后连接电源。指示灯将显示**红色常亮** — 表示 USB 正在初始化。

### 2. 进入配网模式

USB 设备就绪后，指示灯变为**紫色闪烁** — 表示设备正在通过 BLE 广播配网服务。

### 3. 打开桌面客户端

启动桌面客户端（macOS / Windows）。客户端会自动通过 BLE 广播发现您的设备。

> BLE 广播中嵌入了设备的真实 MAC 地址和状态标志（是否已激活 / 是否已配置 WiFi），客户端无需连接即可识别设备。

### 4. 激活设备

如果设备尚未激活，客户端会提示输入**激活码**。请输入随设备提供的激活码。

- 激活码是基于设备唯一 MAC 地址的 ECDSA P-256 签名
- 验证通过后，激活码存储在 NVS 中 — 只需激活一次
- 激活过程中指示灯显示**紫色常亮**

### 5. 配置 WiFi

客户端会扫描附近的 WiFi 网络，选择您的网络并输入密码。WiFi 凭据将存储在设备的 NVS 中。

### 6. 配网完成

激活和 WiFi 都配置完成后，设备会**自动重启**。重启后：

- 指示灯显示**绿色常亮** — 设备已进入正常 HID 模式
- WiFi 自动使用已存储的凭据连接
- 设备已准备好与主机进行 BLE 配对

## 连接主机（日常使用）

配网完成后，设备作为标准 BLE HID 设备运行。连接电脑、手机或平板：

1. 在主机的蓝牙设置中搜索 **"Loommii-HID"**
2. 选择配对 — 主机会显示一个 **6 位配对码**
3. **在 USB 键盘上输入这 6 位配对码**，然后按 **Enter** 提交
4. 指示灯变为**绿色常亮** — 连接成功，即可使用

> 配对码输入过程中随时按 **Esc** 可取消配对。

### 连接更多主机

如需连接第二或第三台主机：

1. 直接在第二台电脑上搜索 **"Loommii-HID"** 并配对（第一台不会断开）
2. 重复上述配对步骤
3. 按 `Scroll Lock + 1` / `2` / `3` 在已连接的主机间切换

所有主机共享同一个 BLE 身份，无需重启或重新配对。

## 快捷键参考

| 快捷键 | 功能 |
|--------|------|
| `Scroll Lock + 1` | 切换到已连接的第 1 台主机 |
| `Scroll Lock + 2` | 切换到已连接的第 2 台主机 |
| `Scroll Lock + 3` | 切换到已连接的第 3 台主机 |
| `Scroll Lock + Esc` | 解绑当前活跃设备（清除配对信息） |

## 从 V2.x 升级

V3.0.x 引入了全新的配网和激活系统。从 V2.x 升级时：

1. **需要恢复出厂设置** — 按住重置按钮或使用桌面客户端的"恢复出厂"功能
2. 恢复出厂后，设备进入配网模式
3. 按照上述首次设置步骤完成激活和 WiFi 配置
