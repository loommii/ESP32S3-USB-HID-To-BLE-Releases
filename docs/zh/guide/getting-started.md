# 首次使用

请按照以下步骤首次设置您的 USB HID 转 BLE 桥接器。

## 准备工作

- 已烧录固件的 ESP32-S3 开发板
- USB 键盘和/或鼠标
- 支持蓝牙的电脑、手机或平板

## 详细步骤

### 1. 上电

将 USB 键盘和/或鼠标插入 ESP32-S3 开发板，然后连接电源。指示灯将显示**红色常亮** — 表示 USB 正在初始化。

### 2. BLE 广播

USB 设备就绪后，指示灯变为**紫色闪烁** — 表示正在 BLE 广播，设备名为 **"Loommii-HID"**。

### 3. 配对

在电脑或手机上搜索可用蓝牙设备，选择 **"Loommii-HID"**。主机将显示一个 **6 位配对码**。

### 4. 输入配对码

**在 USB 键盘上输入这 6 位配对码**，然后按 **Enter** 提交。指示灯将变为**紫色常亮**，表示正在等待输入。

> 配对码输入过程中随时按 **Esc** 可取消配对。

### 5. 开始使用

配对成功后，指示灯变为**绿色常亮** — 正常工作中。

恭喜！您的有线 USB 设备现在已是无线设备。

### 6. 连接更多主机

如需连接第二或第三台主机：

1. 直接在第二台电脑上搜索 **"Loommii-HID"** 并配对（第一台不会断开）
2. 重复上述配对步骤 3-5
3. 按 `Scroll Lock + 1` / `2` / `3` 在已连接的主机间切换

所有主机共享同一个 BLE 身份，无需重启或重新配对。

## 快捷键参考

| 快捷键 | 功能 |
|--------|------|
| `Scroll Lock + 1` | 切换到已连接的第 1 台主机 |
| `Scroll Lock + 2` | 切换到已连接的第 2 台主机 |
| `Scroll Lock + 3` | 切换到已连接的第 3 台主机 |
| `Scroll Lock + Esc` | 解绑当前活跃设备（清除配对信息） |
