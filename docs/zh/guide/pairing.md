# 配对与切换

该桥接器使用单一 BLE 身份，支持最多 3 台主机同时连接，并可在它们之间快速切换。

> **前提条件**：设备必须先完成配网（激活 + WiFi 配置）才能进入正常 HID 模式。首次设置请参见[首次使用](/zh/guide/getting-started)。

## 设备名称

所有连接共享同一个 BLE 设备名：

| BLE 名称 |
|----------|
| **Loommii-HID** |

## 配对新设备

1. 确保开发板已上电并连接了 USB 设备，指示灯显示**绿色常亮**（正常模式）
2. 在目标主机的蓝牙设置中搜索 **"Loommii-HID"**
3. 选择该设备 — 主机会显示一个 **6 位配对码**
4. **在 USB 键盘上输入这 6 位配对码**，然后按 **Enter** 提交
5. LED 保持绿色常亮 — 配对成功，即可开始使用

> 配对码输入过程中，随时按键盘上的 **Esc** 可取消配对。

## 连接更多主机

直接在第二台（或第三台）电脑上搜索 **"Loommii-HID"** 并配对，已连接的主机不会断开。

## 切换主机

使用 `Scroll Lock` 键作为修饰键：

| 快捷键 | 功能 |
|--------|------|
| `Scroll Lock + 1` | 切换到已连接的第 1 台主机 |
| `Scroll Lock + 2` | 切换到已连接的第 2 台主机 |
| `Scroll Lock + 3` | 切换到已连接的第 3 台主机 |

切换瞬间完成，无需重启。已配对的主机会自动重连。

## 解绑

如需解绑当前活跃设备：

| 快捷键 | 功能 |
|--------|------|
| `Scroll Lock + Esc` | 解绑当前设备（清除配对信息） |

此操作会清除当前活跃设备的绑定信息。如需再次使用该主机，需要重新配对。

## 配对过程中的 LED 指示

| 状态 | LED |
|------|-----|
| 广播中（可配对） | 紫色闪烁 |
| 配对码输入中 | 紫色常亮 |
| 已连接就绪 | 绿色常亮 |

完整的 LED 状态表请参见 [LED 状态参考](/zh/guide/led-status)。
