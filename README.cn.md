# USB HID → BLE 蓝牙桥接器

**版本: V3.0.2**

> **V3.0.2** — 修复 USB 长时间使用后键盘鼠标停止响应的间歇性卡死问题，提升长时间运行时的 USB 通信稳定性。
>
> **V3.0.1** — BLE 多连接稳定性修复：msys mbuf 池扩至 24（恢复默认）、启用乐鑫多连接优化、组合键不再透传数字键、移除 LED 轮询模块消除跨主机 Output Report 冲突。
>
> **V3.0.0** — 桌面客户端全新架构（三层分离重构）；BLE 配网（无需 USB 线即可完成首次设置）；设备激活码验证；3 个 HID 槽位独立命名与设备图标。移除 OTA 升级功能，合并分区为单一固件分区。
>
> **V2.2.0** — 多设备切换架构重写：单一 BLE 身份 + 最多 3 台主机同时连接，热键切换无需重启。
>
> **V2.1.0** — 新增桌面客户端：LED 亮度百分比可调；滚轮方向按设备独立存储。
>
> **V2.0.0** — 从 [ESP32S3-USB-Keyboard-To-BLE](https://github.com/loommii/ESP32S3-USB-Keyboard-To-BLE) 闭源分支，升级为键鼠组合 HID 桥接。

将 USB 有线键盘和鼠标通过 ESP32-S3 转换为蓝牙（BLE）无线键鼠组合设备。单一 BLE 身份支持最多 3 台主机同时连接，热键瞬间切换。

## 首次使用流程

1. 插入 USB 键盘和/或鼠标 → 上电 → **红灯**亮（USB 初始化）
2. 灯变 **紫色闪烁** → 板子开始 BLE 广播（设备名：**"Loommii-HID"**）
3. 在电脑/手机蓝牙中搜索 **"Loommii-HID"** 并配对
4. 主机屏幕会显示一个 **6 位配对码**
5. **在 USB 键盘上输入该配对码**，然后按 **Enter** 提交
6. 灯变 **绿色** → 配对成功，开始使用
7. 如需连接第二台设备：直接在第二台电脑上搜索 **"Loommii-HID"** 并配对（第一台不断开）
8. 按 `Scroll Lock + 1` / `2` / `3` 在已连接的设备间瞬间切换

> 配对码输入过程中随时按 **Esc** 可取消配对。

## 桌面客户端

桌面客户端（macOS / Windows），通过 BLE 或 WiFi 局域网连接设备：

- **设备发现** — 自动扫描附近 BLE 设备 + 局域网 mDNS 设备
- **设备激活** — 输入激活码完成设备身份认证
- **WiFi 配网** — 通过 BLE 加密通道扫描网络、提交凭据，无需 USB 线
- **HID 槽位管理** — 查看 3 个 BLE 连接槽位状态，自定义设备名称与平台图标
- **设备设置** — LED 亮度（0-100%）、滚轮方向反转
- **设备操作** — 重启、清除配对、重配 WiFi、恢复出厂
- **暗色/亮色主题切换**

## 功能特性

- **键鼠组合桥接** — 同时支持 USB 键盘和鼠标，BLE 端呈现为单一组合 HID 设备
- **鼠标运动平滑引擎** — 环形缓冲区 + 定时器重采样 + 残差补偿，确保鼠标移动流畅无卡顿
- **跳过非输入接口** — 自动忽略游戏外设的宏键/RGB 控制等 NONE 协议接口，节省 USB 通道资源
- **Boot/Report 协议自适应** — 自动切换两种 USB HID 协议，兼容主流和游戏外设
- **多设备同时连接** — 单一 BLE 身份，最多 3 台主机同时连接，热键切换无需重启
- **低延迟连接参数** — 主动请求 7.5ms~10ms 连接间隔，实际间隔由主机协商决定
- **自动重连** — 已配对主机断开后自动恢复广播，主机侧可自动重连
- **键盘键入配对码** — 配对码直接在 USB 键盘上输入，无需屏幕或其他按键
- **快捷键切换/解绑** — Scroll Lock 修饰键组合操作，无需额外按键
- **设备激活码** — ECDSA P-256 签名验证，通过桌面客户端或 BLE 通道激活
- **LED 亮度可调** — 通过桌面客户端调节板载指示灯亮度（0-100%）
- **滚轮方向按设备独立** — 每个 BLE 设备独立存储滚轮方向（标准/反向），Mac 用户推荐反向

## LED 状态说明

| 状态 | 颜色 | 说明 |
|------|------|------|
| USB 未连接 | 红色常亮 | USB 设备未插入或未就绪 |
| BLE 广播中 | 紫色闪烁 | USB 已就绪，等待主机连接 |
| 已连接 | 绿色常亮 | USB + 至少 1 台 BLE 主机已连接，正常工作中 |
| 切换目标 | 绿色闪烁 | 刚通过热键或客户端切换了活跃目标槽位 |
| 配对码输入中 | 紫色常亮 | 等待用户在键盘上输入配对码 |
| 错误 | 红色常亮 | USB 通信异常 |

## 快捷键操作

**Scroll Lock** 作为修饰键（先按 Scroll Lock 再按功能键）：

| 快捷键 | 功能 |
|--------|------|
| `Scroll Lock + 1` | 切换到已连接的第 1 台主机 |

| `Scroll Lock + 3` | 切换到已连接的第 3 台主机 |

## 已知问题

### USB 间歇性卡死（V3.0.2）

部分设备在长时间使用后可能出现 USB 键盘和鼠标停止响应的间歇性卡死，无任何错误日志或崩溃信息。USB 控制器静默停止传输数据，但 WiFi/HTTP 和 BLE 连接保持正常。

**根因定位**: ESP32-S3 的 DWC2 USB 控制器存在硬件设计缺陷（HW erratum），经乐鑫工程师确认为芯片级问题，跟踪于 [GitHub Issue #14996](https://github.com/espressif/esp-idf/issues/14996)（仍开放）。高轮询率游戏鼠标（500-1000Hz）更容易触发，但普通 USB HID 设备也同样可能遇到。

**V3.0.2 缓解措施**: 将 USB HID 回调函数最小化——仅执行原始数据拷贝到无锁环形缓冲区，由专门的调度任务负责后续处理。该方案降低触发概率但无法根除。
